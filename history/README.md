# 历史快照来源

仓库在导入时未发现本地 Git 元数据，无法恢复原始逐次提交。当前提交链按照可确认的发布版本补录，提交时间为导入时间，不伪造开发时间。

| 版本 | 来源 | 状态 |
|---|---|---|
| v0.1.0 | 原始发布 ZIP 中 app.asar 提取的运行源码，附原安装脚本 | 已知安装/封装问题，归档版本 |
| v0.1.1 | Codex 修复并验收的独立源码 | 安装与启动验收通过 |
| v0.1.2 | 从保留的 0.1.2 安装包内 app.asar 恢复运行源码；构建配置与用户脚本工程来自现存工程 | 后续工程，未沿用 v0.1.1 的验收结论 |

`desktop-unpacked-snapshot/` 来自本地另一个未归档的 resources/app 目录，保留其独立文件状态。它与 v0.1.0 的先后关系未充分确认，因此没有虚构新版本号。

阶段 A/B/C/D 的设计、审计与验收记录位于 `docs/development/`。这些文档不是 Git 提交记录，不能据此恢复每个阶段的完整源码。
