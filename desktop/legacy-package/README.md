# 学习通助手 V0.1 — 使用说明

## 安装（两步）

1. 解压整个压缩包
2. 双击 **`一键安装.cmd`**

装完桌面会出现「学习通助手」图标，程序会自动启动。

卸载：双击 `卸载.cmd`。登录数据会单独询问是否保留。

---

## 使用（三步）

### 1. 登录
打开后左边是学习通网页，正常登录（账号密码、验证码都由你自己输入）。

**登录状态会记住**，下次打开不用重新登录。

### 2. 进入课程
点左上角「课程列表」→ 选你要刷的课 → 点进任意章节。

进入后右侧状态会从「未在课程学习页」变成具体章节名。

### 3. 点「开始自动刷课」

就这一个按钮。程序会：

- 自动找到下一个未完成的任务点
- 正常播放视频（**默认 1.0 倍速，不改进度、不伪造时长**）
- 播到 90% 后等平台自己确认完成
- 确认后自动切到下一节，一直刷下去

**可以最小化到后台**，切到别的窗口不影响刷课。

想停就点「停止」，想暂停点「暂停」（暂停是真暂停，恢复后接着播）。

---

## 自动答题（章节测验）

当你切到课程的「章节测验」页面时：

1. 点「一章一节测验」区域的 **`一键识别并填写`**
2. 等 20 秒左右，右侧会列出每道题的建议答案
3. **核对一下答案**
4. 在网页里手动点「提交」并确认

> 「提交」故意不代点。因为提交后不能改，交给你自己确认更稳。

---

## 常见问题

**右侧一直显示「未在课程学习页」**
你还没进到课程章节页面。点「课程列表」→ 选课 → 点任意章节进去。

**点「一键识别并填写」提示 DSH 未找到**
自动答题需要你电脑上装了 DeepSeek Harness（DSH）。视频刷课不需要它。

**提示 Key 缺失**
需要在 DSH 里配置过 DeepSeek API Key，或设置环境变量 `VISION_API_KEY`。

**窗口关掉后再打开要重新登录**
正常情况下不需要。如果出现了，说明登录数据被清理了（检查卸载时是否选了删除登录数据）。

**杀毒软件报警**
这是自己打包的 Electron 程序，没有数字签名，部分杀软会误报。加白名单即可。

## 目录说明

安装后位置：`%LOCALAPPDATA%\ChaoxingHelper`
登录数据：`%APPDATA%\chaoxing-helper-desktop`

---

## 这版能做什么 / 不能做什么

**能用**
- 自动连续刷视频课，后台运行
- 章节测验的加密题目自动识别 + 填写建议答案

**暂不支持**
- 测验自动提交（留给你手动点）
- 含图片/公式的题目（会提示转人工）
- 判断题、填空题（没验证过）
- 非常长的题干（一张图装不下会失败）

---

## 安全说明

- 学习通运行在独立会话里，网页无法访问你电脑上的文件
- 没有关闭同源策略，没有给网页开放 Node 权限
- API Key 只在主程序内存里用，不进网页、不写日志
- 账号密码、Cookie 不写进任何日志文件
