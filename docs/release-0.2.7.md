# 0.2.7 — 修复视觉做题失败

1. 修复模型已经返回答案，程序仍报“无可用答案”的问题。题目和请求由本地绑定，不再要求模型复述内部题目标识。
2. 桌面做题改用浏览器截图，保留当前页面的字体、选项顺序、图片和公式，不再提取题干、选项后重绘成图片。
3. 截图在后台完成，不需要弹出课程网页，也不会滚动或调整当前界面。
4. 识别失败显示实际原因；题目截图不完整、图片未加载或截图超时时停止处理，不以文字重绘代替。
5. 有题目未取得可用答案时停止自动提交，避免只填一部分就提交整份习题。
6. 模型调用日志记录错误类型，方便定位问题，不再记录内部题目标识。

验证：已用真实习题完成整组截图和视觉分析，全部返回有效选项，未填写或提交线上习题。155 项脚本回归通过，另检查了实际主进程中的截图接口、题目绑定和跨域调用。线上自动提交全流程未在本次核验。

升级前从托盘退出旧程序，再运行安装包。Windows x64；账号、Cookie、API Key、原始题目截图和带参数地址不包含在源码中。
