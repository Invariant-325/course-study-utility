# 0.2.4 本地修复版

- 修复视频位于内嵌页面时，“继续学习”可能误判为正在播放的问题；统一读取实际播放状态，优先控制有当前任务的学习程序。
- 进度无法确认或任务中断时，显示原因和“重试”。
- 设置仅保留头像菜单入口；关于保留在应用菜单，均从侧边栏移除。
- 课程页加入学习策略选择，与设置同步保存。
- “任务队列”改为“接下来怎么学”，按策略列出看哪节视频、做哪节习题；未知进度先检查。
- 加入选章节“做题并提交”。只对本次习题自动提交，不修改常用自动提交开关；已提交的不重复处理，切换课程、章节、刷新或暂停会停止本次做题。
- 删除“需人工”页面。“待完成”分开列出未完成视频和习题。
- 章节状态：都没完成为红色，只完成一部分为黄色，全部完成为绿色，尚未查到进度为灰色。“待完成”保留所属章节状态颜色。
- 声音和更新与其他设置使用相同布局，取消单独大标题；修复开关滑块越过边框的问题。
- 简化界面提示，明确自动做题、自动提交、静音、更新和提前结束视频的含义。

## 检查范围

隔离 Electron 中检查了内嵌播放器恢复、暂停和停止；原生鼠标检查了设置入口、章节颜色、拆分任务、策略同步、单次做题按钮、设置开关、二维码和侧栏宽度。真实主进程检查了策略保存、重载恢复、目录读取和夜间定时取消。单次做题调度检查了章节匹配、重复启动、已提交跳过和停止。
