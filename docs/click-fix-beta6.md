# 0.2.0-beta.6 本地修复

## 鼠标无响应根因

新界面的 #layers > * 将所有覆盖层子元素强制设为 pointer-events:auto。选择器优先级高于 .scrim 的关闭态规则，导致 opacity:0 的全屏弹窗遮罩仍截获鼠标。按钮事件本身存在，程序调用 click() 可以切页，但真实鼠标落在遮罩上。

修复为只允许 data-open=true 的浮层接收输入。保留弹窗打开时的遮罩交互，取消后恢复页面点击。

## 同时修复的界面问题

- 更多按钮误用 window.App，改用已暴露的 __cxApp 引用，恢复显示/隐藏平台网页。
- 最小化、最大化、关闭到托盘及退出菜单接入真实窗口 IPC，不再只显示成功提示。
- 开始、暂停、继续和结束接入课程 Runner；未进入学习页时返回明确原因，不伪报任务已启动。
- 播放按钮状态跟随 Runner，不再使用默认 true 的模拟播放状态。
- 刷新按钮读取实际课程数据；添加任务改为导入当前章节并调用持久化接口，不再添加内存里的示例任务。
- 去除硬编码账户显示，未配置的操作不再伪报成功；退出登录暂提示通过平台账户菜单操作。

## 检查范围

独立 Electron 中先复现原版遮罩阻挡，再用原生鼠标输入事件验证修复版导航、弹窗打开/取消、取消后的点击恢复和应用菜单。接口替身记录确认开始/暂停/结束、最小化/最大化、网页显示及任务导入接口均被实际调用；这不等同于真实课程任务已运行。

本版没有清理或修改用户登录数据，没有上传 GitHub。仍需继续完善的功能包括课程搜索、编辑菜单和新界面完整课程导航；本轮不把这些入口描述为已经实现。旧的课程统计和费用展示仍需单独校准，不作为平台认可学习时长或最终账单证明。

安装前使用托盘菜单退出旧程序；仅关闭窗口会隐藏到托盘。再运行本地 beta6 安装包。当前已打开的旧版窗口不会因源码修复自动更新。
