# 0.2.3 本地修复版

## 学习策略

默认“自动”：从第一章起检查平台完成状态，跳过已确认完成的章节。本章视频、测验等任务全部完成并得到平台确认，才进入下一章。进度未知、测验未提交或未开启自动做题时，停在本章等待处理，不盲目推进。还提供按章完成、优先测验、仅补测验、仅看视频四个手动策略。

自动做题、自动提交、学习策略及提前结束选项存入原有本机配置，重开应用和换章节继续使用，设置变化同步到已挂载脚本。没有历史保存值时，自动做题和自动提交仍默认关闭，不擅自开启提交。

“平台确认完成后提前结束视频”默认开启。它读取当前视频任务的完成标记，平台即使在观看到 90% 时确认完成，也可提前结束并检查本章后续任务；不使用固定百分比推断完成。关闭后，正在播放的视频继续到结尾。过去已经完成的章节仍按策略跳过。

## 进度刷新

增加主动刷新和“刷新进度”按钮。学习开始、章节推进及测验提交后重新读取，运行中定期检查；后台读取同一页面有 30 秒限频，失败不伪造完成。平台确认本章完成时，不继续重复播放旧页面显示的待完成视频。服务器内容不包含可识别目录时，保留待确认状态。

提交过的测验在平台仍未确认时，进入等待确认，避免因旧 DOM 重复作答。后台重新读取只解析 HTML，不执行返回脚本，不构造签名地址，不自动绕过锁定任务或身份验证。

## 按钮与网页同步

侧栏、顶部、当前播放和悬浮按钮统一使用一个控制器。未开始显示“开始学习”，播放时显示“暂停”，暂停后显示“继续学习”，准备期间可取消；命令执行期间禁用重复点击。停止或取消准备会清掉等待启动请求，防止稍后又自动启动。

状态同时读取 Runner 和当前实际视频播放器，约 750 毫秒轮询一次，网页手动暂停/恢复会更新按钮。手动切换章节后解除旧章节自动调度，不暂停新播放器。暂停也会停止正在处理的章节测验，已发送到平台的提交请求无法撤回。

## 夜间与防休眠

保留网页旁的夜间开关与独立 30 秒倒计时胶囊。使用 Electron prevent-app-suspension 阻止应用工作期间的自动睡眠，允许显示器关闭；不修改系统电源计划。夜间模式或任务仍在运行时维持保护，两者都结束或退出应用后释放。手动睡眠、合盖、断电等系统行为不承诺阻止。

## 验证范围

脚本回归 140 项通过；新增默认自动策略、本章任务未完成不推进、服务端完成覆盖旧状态、未知进度不盲点、优先回补测验、网页换章解除旧调度、提前结束须平台标记及关闭选项不提前停止等检查。

真实 Electron 隔离环境验证统一开始/暂停/继续、网页手动暂停/播放、停止与取消等待，以及原生鼠标下各按钮一致性；实际主进程检查设置持久化、界面重载恢复及夜间防休眠标记。定时任务立即取消，没有实际执行息屏，也未验证显示器物理状态或长时间睡眠行为。修复后的流程尚未用真实账号全程验收，本版仅本地交付，未更新 GitHub。
