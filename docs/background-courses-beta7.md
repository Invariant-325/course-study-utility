# 0.2.0-beta.7：后台课程列表与扫码验证

## 使用流程

启动后在后台进入平台个人首页，读取课程列表；支持识别的分页会自动翻页汇总。主界面显示真实课程名称，章节数和进度尚未读取时不显示虚构的完成比例。点击课程卡片会通过平台原始链接进入课程，并尝试使用平台提供的章节学习入口。

若需要手机扫码登录或刷脸，主界面显示平台生成的二维码。本人用手机完成验证后，程序继续观察后台页面。若已经点了开始，则在平台实际进入学习页后启动一次任务；二维码消失本身不作为验证成功的依据。

保留显示原网页入口，用于首次账号密码登录、平台页面变化、二维码过期或无法提取、无法识别章节入口等情况。不是绕过验证码或人脸验证。

## 隐私与行为

课程原始链接和二维码仅在本机运行时使用，二维码不写日志或版本归档。课程名称按文本转义，不能通过课程标题执行 HTML。切换课程会取消此前等待启动的请求；刷新列表不会主动打断进行中的任务。

## 验证范围

本地真实 Electron + 模拟平台已验证分页课程汇总、隐藏网页时读取嵌套帧二维码、二维码过期状态、二维码消失不误判成功、实际进入学习页后只启动一次、运行中禁止列表刷新。主界面原生鼠标测试验证课程选择确实调用后端、二维码显示与显示原网页按钮。实际打包程序的接口、二维码卡片、鼠标导航和 ASAR 与源码一致性已检查。

尚未用用户真实账号完成本版全程扫码刷脸。平台自定义课程文件夹、新版分页、特殊章节入口和非标准二维码页面可能还需适配；遇到这种情况保留原网页处理，不伪报读取或验证成功。

安装前在托盘菜单退出旧版，再运行 beta7 安装包。源码和说明已放共享目录，未上传 GitHub。
