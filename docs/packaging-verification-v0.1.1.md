# 0.1.1 重打包与验收结果

## 交付

- `ChaoxingHelper-0.1.1-Setup-x64.exe`：Windows x64 安装向导，建议优先使用。
- `ChaoxingHelper-0.1.1-win64.zip`：完整免安装包，解压后双击“启动学习通助手.cmd”。
- `ChaoxingHelper-0.1.1-source.zip`：修复后的源码、锁文件、构建脚本和包校验脚本。

原项目与原发布包未覆盖。修改版在独立工作目录构建；本轮只进行本机文件交付，没有上传或发布到外部服务。

## 修复内容

1. 使用 NSIS 安装器替换旧的 CMD 安装流程，支持选择安装目录、桌面和开始菜单入口、Windows 卸载登记。
2. 修正语言过滤参数为数组，保留 `zh-CN.pak` 和 `en-US.pak`；构建阶段缺失任一文件会失败。
3. 启动日志改为用户数据目录中的 `logs/startup.log`，记录启动、ready、面板加载、网页加载、退出及错误。启动失败会显示提示，不再静默吞掉。
4. 修正 iframe 重复遍历：使用直接子 frame 和去重集合，最多枚举 256 个 frame。
5. 关闭窗口时同步关闭独立网页视图。
6. EXE 写入应用图标、中文产品名和 0.1.1 版本资源。免安装启动和诊断脚本使用 ASCII + CRLF。

## 实测通过

- JavaScript 语法检查。
- 中英文资源、EXE、ASAR 结构与打包源码逐字节核对，包内没有开发日志。
- iframe 嵌套、共享节点、循环引用与遍历预算回归检查。
- 安装器静默试装到独立测试目录，退出码 0，应用文件到位。

- 安装版首次启动、同一测试配置下再次启动、免安装版启动：界面控件、预加载桥、设置通信、学习通公开首页、可写启动日志均通过。
- 设置写入后关闭，再次打开能读回持久化的值。

- 两个 ZIP 的 CRC 全量检查通过；免安装 ZIP 内全部应用文件与已验证构建逐字节一致，启动脚本编码和 CRLF 检查通过。

## 验收范围

本轮完成安装与启动封装修复。原有视频与 AI 测验代码保留，但没有重新登录、播放课程或进行答题填充，不能把打包验收视为业务端到端验收。AI 功能仍依赖用户自己的 DeepSeek Harness 与 API 配置。

构建未使用发布者证书，安装包与应用均无数字签名。本轮测试安装已经卸载，交付文件可由用户自行安装。

## 构建环境问题的处理

旧版 NSIS 编译器在受限执行环境中出现 Windows DLL 重定位错误，正常执行权限下能够运行；最终编译与应用验收均在正常执行权限下完成。未修改 Windows 安全设置，也未通过永久关闭 Electron sandbox 规避问题。
