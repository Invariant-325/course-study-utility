# 0.1.7 登录后无效参数修复

在用户实际运行的 0.1.6 窗口中确认：地址是没有参数的 /mooc2-ans/mycourse/stu，网页显示“无效的参数”。该地址是具体课程入口，不能当成无参数课程列表。0.1.6 把已有错误按钮地址用于启动和自动导航，扩大了问题。

0.1.7 改为先访问 https://i.chaoxing.com/base，再点击平台页面自身的“课程”或“我的课程”菜单，保留原生处理器、iframe 目标和完整参数。侧栏“课程列表”按钮也复用相同逻辑。未发现菜单时停留个人首页，不再拼接课程 ID、签名或猜测地址。登录回调和具体课程页面不会被重定向。

本地真实 Electron 集成测试15项通过，覆盖平台菜单参数保留、回调不打断、无菜单不强跳、有效课程链接参数保持，以及上一版 AI iframe、弹窗和回退路径。已覆盖安装到用户本机并实机观察：原有登录状态保留，0.1.7 进入官方个人首页，内嵌页面正常显示“我学的课”和课程卡片，“无效的参数”错误不再出现。本轮没有打开题目或提交答案。未把这一导航验收扩展为所有课程、刷脸及 AI 全流程均通过。
