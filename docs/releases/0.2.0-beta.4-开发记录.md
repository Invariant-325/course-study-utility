# 0.2.0-beta.4：修复「勾选后不立刻生效」

2026-11-11。用户反馈：章节测验的选项勾选了不会立刻生效。

## 根因

用户脚本的 `Config` 是**纯内存缓存**，只在脚本启动时 `load()` 一次：

```js
const cache = Object.assign({}, DEFAULTS);

function load() {
  // 从 kv 读一次，灌进 cache
}

get(key) {
  return cache[key];   // ← 只读内存
}
```

而侧栏面板改的是 kv（`cxNaturalWatch:cfg.<key>`）。

于是：

```
面板勾选 → 写 kv ✅
            ↓
      页面内 cache 没变 ❌
            ↓
Runner 读 Config.get('quizGateEnabled') → 还是旧值 false
            ↓
        闸门不启动，看起来"没生效"
```

只有重新进入学习页（触发 `Config.load()`）才会读到新值。

## 修复

`desktop/ui/app.js` 的 `cfgSet()` 在写 kv 之后，顺手把新值推给页面内的 `Config`：

```js
function cfgSet(key, value) {
  App.kvSet(cfgKey(key), JSON.stringify(value));   // 持久化

  App.evalMain(
    '(function(){var a=window.__cxNaturalWatchApp;' +
      'if(a&&a.config&&typeof a.config.set==="function"){' +
      'a.config.set(' + JSON.stringify(key) + ',' + JSON.stringify(value) + ');' +
      '}})()'
  ).catch(() => {});   // 不在学习页时失败属正常
  return true;
}
```

这样：
- **在学习页**：立即生效（`Config.set` 同时更新 cache 和 kv）
- **不在学习页**：写 kv 成功，下次进入页面 `load()` 时生效

## 影响范围

走 `cfgSet` 的所有开关都一并修好：

| 配置 | 位置 |
|---|---|
| `quizGateEnabled` | 章节测验「自动做题」 |
| `quizAutoSubmit` | 章节测验「自动提交」 |
| `notifyOnManual` | 异常与提醒「需要人工时通知」 |

`Config.set` 本身对 `playbackRate` 有锁定保护（不允许改成非 1.0），这里传的是布尔值，不会触发。

## 未验证

- **实机勾选后闸门是否立刻按新值走**：我这边 Electron 起不来，只验证到代码与产物。需要你装 beta.4 后确认。
- 若仍不生效，可能的下一个怀疑点：`evalMain` 的目标 frame 与 `__cxNaturalWatchApp` 实际挂载的 frame 不一致（当前 `web:eval` 走的是主 frame）。届时请把 `window.__cxNaturalWatchApp` 是否存在、`Config.get('quizGateEnabled')` 的实时返回值发我。

## 一个已知的边界

`Config.set` 会**再写一次 kv**（和 `cfgSet` 的写入重复）。无害，但如果将来加"配置变更事件"，要注意会收到两次。
