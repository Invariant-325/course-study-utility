# 0.2.0 第一部分：内置模型调用（去掉 DSH 依赖）

2026-11-11。对应需求 1「内置模型、用户填 API Key 即可用」。

## 为什么不是真的把 DSH 打包进去

需求原话是「内置 dsh 框架」。技术上把 DSH Desktop（一个 250MB 的 Electron 应用）塞进安装包，既不现实也会让体积翻倍，而且用户本机装了 DSH 才能用的问题根本没解决。

真正要解决的是：**普通用户拿到装好的 App，不需要装任何别的东西，填个 Key 就能用。**

所以采用的是「App 直接调用 DeepSeek API」：使用者不感知 DSH，效果等同于内置。

**先做了可行性实验**（这一步是关键，没有它不敢改）：

```
POST https://api.deepseek.com/chat/completions
model: deepseek-chat
messages: [system: 视觉题目分析引擎提示词, user: [text, image_url(base64 真实题目图)]]

→ HTTP 200
→ content: {"questionId":"q_1","type":"single","answers":["A"],"status":"ok"}
→ usage: prompt 759 + completion 22
```

**答案 A 正确**（全面从严治党核心是加强党的领导）。证明官方 API 直接支持图片输入，不需要 DSH 中转。

## 改动

### 主进程（`desktop/main.js`）

| 变化 | 说明 |
|---|---|
| `askVision` 改为直连 | 不再 spawn `dsh --profile headless`，改为 `fetch(api.deepseek.com)`，图片以 data URL 内联 |
| 系统提示词内置 | `SYSTEM_TASK` 常量直接写在代码里，用户看不到也不用改 |
| 新增凭据加密存储 | `safeStorage.encryptString` → `userData/credentials.bin` |
| 凭据优先级 | 本 App 填的 > `VISION_API_KEY`/`DEEPSEEK_API_KEY` 环境变量 > 本机 DSH 凭据（兼容老用户） |
| 新增 4 个 IPC | `model:setKey` / `model:clearKey` / `model:test` / `vision:status` 返回 keySource+masked |
| `runHeadless` 保留 | 函数还在但**已无调用**（grep 确认只有定义），留作将来可选后端 |

**不再产生临时图片文件**——图片直接以 base64 放进请求体，少一个临时文件泄漏点。

### 渲染层

- `preload.js`：暴露 `setModelKey` / `clearModelKey` / `testModel`
- `ui/index.html`：「运行环境」折叠块换成「模型设置」卡片（密码输入框 + 保存/测试/清除）
- `ui/app.js`：新增 `bindModel` / `pollModel`，去掉旧的 `pollEnv`

## 未验证

- 在 App 里填 Key → 保存 → 测试连接 → 自动答题 的**完整人工流程**没跑过（本会话 Electron 起不来）

3. 再进章节测验页试「一键识别并填写」
