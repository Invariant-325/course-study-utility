# 0.1.9 新功能：夜间静默 / 自动提交 / 自动做题开关 / 管理员安装

2026-11-11。四项需求实现记录与验证边界。

## 一、夜间静默模式

**位置**：侧栏新增「夜间静默」卡片。

**行为**：

1. 点「开启夜间模式」→ 弹确认框，说明会静音、30 秒后关屏、并自动打开两个开关
2. 确认后：
   - 立刻把**网页音视频**静音（`webContents.setAudioMuted(true)`，不动系统音量）
   - 30 秒后关闭**显示器**
   - 同时自动勾选「自动做题」和「自动提交」
3. 30 秒内按钮变成「取消（N 秒后关屏）」，点它可撤销（不会关屏、会取消静音）
4. 进入夜间后按钮变成「退出夜间模式」，点它取消静音并恢复

**关屏实现**：主进程 spawn `powershell.exe` 执行 P/Invoke：

```csharp
SendMessage(HWND_BROADCAST=0xffff, WM_SYSCOMMAND=0x0112, SC_MONITORPOWER=0xF170, 2)
```

`2` = 关闭显示器。移动鼠标或按键即可点亮（Windows 原生行为，不需要我们恢复）。

**静音只作用于网页**，不改系统音量——避免影响用户其他程序。

**失败处理**：任一步失败都会在 `night:changed` 事件里带 `error` 字段，面板显示「部分步骤失败：...」，不假装成功。

## 二、自动提交开关

**位置**：「夜间静默」卡片内的勾选框。

**对应配置**：`quizAutoSubmit`（用户脚本 Config，默认 **false**）。

**联动**：`80-runner.js` 的闸门里改成

```js
submit: Config.get('quizAutoSubmit') === true
```

**关键修正**：只填写不提交时，测验在平台侧仍未完成。若此时闸门放行，下一轮会重复进入同一测验形成死循环。所以新增分支：

```js
if (result.phase === 'filled') {
  enterQuizManual('本章测验已填写但未提交（自动提交未开启）。请核对答案并在页面点「提交」，然后点「继续」');
  return 'blocked';
}
```

即：**未开自动提交 → 填完就停下等你提交**。

## 三、自动做题开关

**位置**：「视频自动化」卡片底部的勾选框。

**对应配置**：`quizGateEnabled`，本轮**默认值从 true 改为 false**。

| 状态 | 行为 |
|---|---|
| 勾选 | 本节视频播完 → 做完本章测验 → 再切下一节 |
| 不勾选（默认） | 只看视频，播完直接切下一节，跳过章节测验 |

**视频播放中弹出的题目不受此开关控制**，仍会自动作答——否则视频无法继续播放。

测试 `tests/qa-quiz-gate.mjs` 原本依赖「默认开启」，已改为显式 `Config.set('quizGateEnabled', true)`。

## 四、安装程序默认管理员权限

`desktop/package.json`：

```json
"nsis": {
  "perMachine": true,
  "allowElevation": true,
  "oneClick": true
}
```

装到 `C:\Program Files\课程伴学工具`，安装时会请求 UAC 提权。

**兼容性**：`appId`、`userData`（`%APPDATA%\chaoxing-helper-desktop`）、`persist:chaoxing` 均未变，升级不丢登录。

**注意**：从 0.1.8（用户级安装，`%LOCALAPPDATA%`）升到 0.1.9（机器级，`Program Files`）属于**更换安装位置**。旧目录可能残留，建议装完手动删掉 `%LOCALAPPDATA%\Programs\课程伴学工具`（如果存在）。
