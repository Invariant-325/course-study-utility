# 0.2.0-beta.2：课程总览 + 待办任务队列 + 开关归位

2026-11-11。承接 beta.1（内置模型调用）。

## 一、开关归位（按用户要求）

beta.1 里「自动做题」在视频卡片、「自动提交」在夜间卡片，位置不合理。本版调整：

| 位置 | 内容 |
|---|---|
| 视频卡片 | 只剩 开始/暂停/停止 |
| **章节测验卡片** | **自动做题** + **自动提交** 两个勾选（正常情况也可用） |
| 夜间卡片 | 只有一个「开启夜间模式」按钮 + 一行说明 |

**夜间模式不再有单独的勾选**：开启夜间 = 全自动，代码里直接 `setQuizFullyAuto()` 把两个开关置为 true，并同步 UI 勾选状态。

页面上的说明文字：

> 夜间模式 = 自动做题 + 自动提交，开启后无需再单独设置

配置项没变：`quizGateEnabled`（默认 false）、`quizAutoSubmit`（默认 false）。

## 二、课程总览仪表盘

**位置**：侧栏「课程总览」卡片。

| 字段 | 来源 |
|---|---|
| 章节数 | `CourseTree.catalogEntries().items.length` |
| 待完成 | `readCatalogSummary()` → `已完成任务点: N/M` |
| 最近学习 | `Config.readCursor().jobTitle` |
| 章节列表 | 默认折叠，展开后逐条列出，带 `N 个待完成` 标记 |

**只读**：不改页面、不推断完成度、不把"客户端观察到"当"平台确认"。

数据链路：主进程 `course:overview` → 在页面执行 JS 读 `window.__cxNaturalWatchApp.tree` → 回传结构化数据。5 秒轮询刷新。

未进入学习页时显示「请先进入课程学习页」。

## 三、待办任务队列

**位置**：侧栏「待办任务」卡片。

**数据模型**：

```js
{
  id, courseName, chapterTitle, type,
  priority: 0|1|2,          // 低/中/高
  status: 'todo'|'doing'|'done'|'manual',
  note, createdAt, updatedAt
}
```

**持久化**：`%APPDATA%\chaoxing-helper-desktop\tasks.json`，重启不丢。

**四态显示**（彩色徽章）：

| 状态 | 颜色 |
|---|---|
| 未开始 | 灰蓝 |
| 处理中 | 蓝 |
| 已完成 | 绿 |
| 需人工 | 橙 |

**操作**：

- 「从当前课程导入」：读取当前课程章节列表，按是否有待完成自动给优先级（有待完成=高，否则中），已存在的章节不重复导入
- 每行下拉框可直接改状态
- 每行「删」移除
- 「清理已完成」批量移除 `done`

**IPC**：`tasks:list` / `tasks:add` / `tasks:update` / `tasks:remove` / `tasks:save`

## 四、版本号带 beta

按用户要求，此后每次改动都带 beta 序号。本版 `0.2.0-beta.2`。

**顺带修的问题**：EXE 版本资源必须是纯数字，`0.2.0-beta.2` 直接写会失败。所以：
- `build/after-pack.cjs` 加 `numericVersion()`，把 `0.2.0-beta.2` 归一成 `0.2.0` 再写进 EXE
- `Build.ps1` 校验时也用归一化后的数字比对，避免误报

安装包文件名仍是完整的 `CourseStudyUtility-0.2.0-beta.2-Setup-x64.exe`。
