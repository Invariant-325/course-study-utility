# 0.2.9 · 直播回放与阅读任务

本地验收版，尚未上传 GitHub。

1. 直播回放和图书阅读归入视频类任务，纳入自动、按章、先做习题和只看视频策略；只做习题策略不启动这些任务。
2. 自动打开平台提供的回放播放器或试读入口，完成状态仍读取平台记录。直播或阅读离开前台时暂停，不模拟观看、翻页或伪造时长。
3. 修复弹出回放/阅读页后丢失课程目录上下文的问题。暂停、结束和返回课程保留原有页面；兼容平台复用已有回放窗口。
4. 任务队列区分观看回放和打开阅读，并补充策略说明。

实际检查：两次回放均可打开、播放、暂停并返回课程；图书试读入口打开后，平台的阅读待完成数由 1 变为 0。回放仅做短时播放测试，没有等待整场观看达到 90%，不宣称已替用户完成直播任务。
