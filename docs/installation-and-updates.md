# 安装与更新

从 Releases 下载对应版本的 Setup-x64.exe，先正常退出旧版再运行安装器。应用内“更新说明”只展示提示，没有自动更新功能。

0.1.9 开始采用机器级安装，需要管理员权限。0.1.8 及更早采用当前用户安装，升级时会改变安装位置，旧安装可能残留。请确认运行的是新版本后再处理旧安装，不要删除登录数据目录。

安装包暂未数字签名，运行时可能出现 SmartScreen 信誉提示。管理员权限提示与 SmartScreen 是不同机制，产品名和图标资源不等于签名。

## AI 与测验

侧栏“一键识别并填写”会显示和填写结果，提交前请自行核对。章节测验的自动做题、自动提交在新配置下默认关闭，旧版保存的设置会保留。开启夜间模式会同时开启两者。视频中的弹题沿用原有处理逻辑，不受这两个章节测验开关控制。

未开自动提交时，测验填写后暂停等待用户提交。开启自动提交后可能执行提交与二次确认。图片、公式和部分题型可能需要人工处理。

验证码和人脸验证由本人完成。登录状态的有效期由平台决定。
