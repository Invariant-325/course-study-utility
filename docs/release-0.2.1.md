# 0.2.1

## 界面与操作

- 独立关于页面，提供 GitHub 主页、仓库、问题反馈及非官方兼容声明。
- 新 Logo 应用于窗口、EXE、安装器和托盘图标。
- 总览更名主页，读取课程封面和平台昵称、头像；当前课程跟随主题配色强调。
- 设置集中管理模型、日志、网页默认静音及启动更新检查。更新检查读取 GitHub 最新正式版，不自动安装。
- 网页入口改为带文字的胶囊按钮；重做操作提示，移除无意义的“撤销”。调整界面措辞与强调色。
- 侧栏右侧分隔线支持拖动，主页自动伸缩；宽度保存在本机，双击或 Home 恢复默认，方向键微调。

## 课程与章节

- 章节名称优先提取标题节点，清理尾随任务点数量和待完成状态，保留正常标题中的“任务点”等词。
- 明确区分全部完成、仅视频完成、仅测验完成、均未完成；未知状态仍为灰色。
- 已进入并读取的课程按账号缓存真实进度；未读取课程不显示装饰性进度条。
- 保留后台课程读取和主界面二维码验证，不以二维码消失判断验证成功。

## 检查记录

隔离 Electron 环境下通过原生鼠标事件检查导航、课程选择、扫码面板、设置、关于、侧栏拖动、宽度恢复和收起展开。模拟平台检查昵称/头像/封面提取、章节名称及任务类型、按账号缓存进度；实际 WebContents 静音与设置持久化通过。更新接口使用受控响应检查版本比较。安装包核对 ASAR 与源码一致性及资源完整性。

上述检查未使用真实账号完成学习平台全程业务，不代表所有平台页面均已适配。升级前从托盘退出旧程序。
