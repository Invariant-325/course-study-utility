# 0.2.2 本地修复包

## 夜间模式入口恢复

恢复新界面遗漏的夜间模式入口，放在标题栏“网页”胶囊旁边。开启后出现独立倒计时胶囊，显示距息屏的剩余秒数，可用 × 或再次点击开关取消。30 秒后关闭显示器并将课程网页静音，不更改系统音量，也不更改做题和提交设置。运行中的课程任务保持运行。倒计时胶囊位于标题栏，显示原网页时也可操作。

原生鼠标测试确认开关、独立胶囊与取消操作；实际主进程测试确认 30 秒定时建立后可立即取消。本次未实际执行息屏命令，未验证显示器物理状态。

## 课程目录与启动

修复刷脸完成后课程主页已有章节目录，App 却仍显示“未进入学习页”的问题。原先 course:overview 必须找到具体学习页里挂载的 tree；自动导航又只寻找 studentstudy 的普通链接，无法处理课程主页通过 onclick 打开的章节。

现在从各个平台 frame 独立读取目录与真实汇总，无需先挂载学习脚本。课程主页可显示章节和进度；点击开始后，优先选择平台标记待完成的非锁定章节，调用原有 DOM 点击事件。章节点击也接入主界面；标题和当前页面再次匹配，避免列表变化后误点。进入实际学习页才启动 Runner，页面切换导致执行失败时保留启动请求。

未知完成状态仍保持待确认，不用二维码消失推断验证成功。不构造课程签名地址，不绕过刷脸或锁定章节。

## 网页访问限制

- 内置平台网页只允许 HTTPS 的 chaoxing.com、xuexitong.com 及其子域，使用标准 443 端口；拒绝带用户名/密码的地址、IP 地址、相似域名、HTTP、file/data 等页面导航。
- 同时检查主动打开、页面跳转、HTTP 重定向、弹窗、子框架及浏览历史。会话请求层补充拦截，防止 loadURL 绕过页面事件。
- 平台打开的 about:blank 空白弹窗可继续导航，但其后续目的地仍需通过检查。srcdoc/空白子文档不产生外部网络导航。
- 不忽略证书错误；无效证书拒绝连接。保持 contextIsolation、sandbox、webSecurity，禁止运行不安全混合内容。
- 本地控制面板禁止自行跳转和创建弹窗；关于与更新按钮仅能通过明确的 GitHub 链接白名单打开系统浏览器。
- 此限制针对文档导航。平台图片、视频等资源并未统一限制到上述两个域，避免破坏 CDN 内容；AI 与更新服务使用各自接口。没有更改系统 DNS 或系统证书库。

域名白名单不能验证 DNS 答案是否可信；DNS 被改到冒充服务器时，HTTPS 证书校验提供额外保护。该方案不承诺抵御平台自身被入侵、有效证书被盗用或系统信任根已被篡改等情况。

参考：[Electron 导航事件](https://www.electronjs.org/docs/latest/api/web-contents)、[Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security)。
