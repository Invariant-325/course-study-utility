# 0.1.6 四项修复与核验

本版只在本地交付，没有上传 GitHub。

## 变更

1. 登录保存：固定 userData/sessionData 路径；退出时等待 Cookie 与设置落盘。原生持久 Cookie 由 Chromium 管理；会话型 Cookie 使用 Electron safeStorage 在 Windows 本机加密保存并恢复，退出登录后的删除会同步保存。会话快照本地恢复窗口为七天，平台可随时撤销登录状态。不能保证平台过期或强制刷脸后仍免登录。
2. AI：按实际 DOM 查找测验，不再只匹配两种网址；给跨域嵌套 iframe 提供受限的 App 接口，保持 Node 关闭和 sandbox 开启。普通题与加密文本题均进入视觉通道；等待字体加载。App 内 QuizVision 直接调用内置主进程，不再依赖 localhost:8788。显式传递用户配置的 Key 给独立 headless 子进程；修正 Windows 带空格的启动路径、题目 ID 校验和识别失败提示。图片/公式及不支持的题型仍提示人工处理，不能声称支持全部题型。
3. 导航：启动打开课程入口，由平台执行 SSO；在已知个人首页且具有用户身份 Cookie 时进入课程列表，不抢占登录、扫码、人脸验证和课程详情页。
4. 回退：新窗口接管为独立的 WebContentsView，保留原生 opener、POST 和延迟赋值关系；返回时跳过空白历史页，必要时恢复来源视图。网页背景为白色，加载失败时显示可重试提示；网页进程退出时提供恢复路径。

## 已验证

- 用户脚本测试 132/132 通过。
- 真实 Electron、本地 HTTP 页面和模拟模型：登录首页转课程、验证页面不受打断、跨域两层 iframe、普通题识别填写且不提交、自动测验视觉接口、顶层新网址测验、加密标记题、模型失败展示和按钮恢复、原生 opener、延迟空白窗、普通后退、失败后恢复，12 项通过。
- 另两次独立重启验证：会话型 + 持久 Cookie 恢复；退出登录后再次重启不恢复已删除的会话。
- 一次真实 DeepSeek headless 调用：自制英文 2+2 PNG，返回 B，约 3.8 秒。仅验证图片调用链，没有使用真实平台题目或提交答案。
- 测试使用独立配置目录及虚构 Cookie，未清理用户现有登录数据。

## 尚未验证

真实账号登录、二维码刷脸后的服务端回调和真实课程全流程仍需用户实际验证。未把本地仿真测试等同于平台端到端验收。模型识别正确率、复杂公式图片以及其他页面改版不在本轮结论内。

## 本地安装

先正常退出旧版，再运行 CourseStudyUtility-0.1.6-Setup-x64.exe 覆盖安装。首次安装本版后登录一次，正常关闭再重开检查状态；只有新版本运行后才会生成加密的会话快照。课程中打开测验后使用右侧“只扫描”和“一键识别并填写”，核对结果后自行决定提交。
