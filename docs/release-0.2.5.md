# 0.2.5 — 自动读取目录进度

## 修复

- 进入课程立即读取已渲染的网页目录。完成勾、待完成数字、提示文字及显式计数使用同一套解析规则。
- 补充真实平台使用的 `icon_Completed` 完成标记。`catalog_points_yi` 是待完成标记，不能当作完成。
- 目录由网页异步加载。后台刷新复用平台已经发出的目录请求，不再依赖重新请求一个空目录的整页 HTML；按服务器声明的中文编码解码。
- 页面加载和目录状态变化立即通知主界面更新，1.5 秒轮询兜底。新目录状态优先于旧缓存；平台目录明确全部完成时，旧任务图标不再阻止完成判定。
- 已知待完成数量不再显示为“进度未知”；尚未区分视频和习题的章节先自动检查，不虚构两种任务都未完成。
- 保留章节编号。修复长章节标题被截断后无法匹配当前章节的问题。
- 主页立即更新当前课程进度。平台未提供任务点总数时，显示真实的已完成章节数/总章节数，并标注“章节”。
- 侧栏课程点击实际打开所选课程。
- 学习策略、章节选择、做题并提交、刷新进度统一为 36px 高度和胶囊圆角。

## 验证

使用当前登录账号的现有平台目录请求进行了六次只读核对，结果一致：真实目录全部章节均读到进度，完成项和待完成数量与当前网页的完成勾和数字对应。没有进行播放、答题或提交。

使用本次真实目录响应在隔离 App 主进程中验证了初始读取、完成标记解析与界面呈现；连续三次改变隔离目录标记，界面均无需点击刷新或确认便自动更新，课程进度缓存也同步改变。隔离修改不影响线上课程。

脚本回归 149 项通过。原生鼠标检查了入口、章节颜色、任务拆分、控件尺寸与设置；真实课程播放到结束后的自动推进和 AI 作答提交流程未在本次验证。

本版仅本地交付，未上传 GitHub。账号、Cookie、原始带参数地址和真实页面诊断均不包含在交付源码中。
