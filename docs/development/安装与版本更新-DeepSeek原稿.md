# 安装与版本更新说明

## 当前机制：手动覆盖安装

这个程序**没有自动更新**。更新方式就是：

1. 退出正在运行的「学习通助手」
2. 双击新版本安装包（如 `ChaoxingHelper-0.1.3-Setup-x64.exe`）
3. 装完自动启动

不需要先卸载旧版本。

## 为什么能直接覆盖

| 项 | 值 | 作用 |
|---|---|---|
| `appId` | `com.local.chaoxing.helper` | NSIS 用它识别"同一个应用"，所以新版会覆盖旧版而不是并存 |
| `perMachine` | `false` | 装到当前用户目录，不需要管理员权限 |
| `executableName` | `ChaoxingHelper` | 从 0.1.1 起固定，不再变化 |
| `oneClick` | `true` | 一键安装，无向导页 |

**只要 `appId` 不变，任意版本都能互相覆盖。** 后续版本我会保持这个 appId。

## 升级时什么会保留

全部保存在 `%APPDATA%\chaoxing-helper-desktop`，**覆盖安装不会动它**：

| 内容 | 说明 |
|---|---|
| 学习通登录状态 | 独立 session 分区（`persist:chaoxing`），登录一次长期有效 |
| `store.json` | 面板配置 |
| `dsh-home/` | 视觉答题的 DSH profile |

**所以升级不需要重新登录。**

卸载时也会询问是否删除这些数据（默认保留）。

## 安装位置

程序：`%LOCALAPPDATA%\Programs\chaoxing-helper-desktop`
数据：`%APPDATA%\chaoxing-helper-desktop`

想确认自己装的是哪版：打开程序，右下角显示「版本 0.1.3」。

## 已知限制

1. **没有版本回滚**。装回旧版需要重新运行旧安装包。
2. **没有更新检查**。程序不联网，右下角「更新说明」按钮只弹一段说明文字，不会去下载。
3. **没有代码签名**。覆盖安装或首次运行时 Windows 可能弹 SmartScreen 提示，选择"仍要运行"即可。这不是病毒，是本地自建包的常规现象。
4. **同一目录不会残留旧 exe**。0.1.1 起可执行文件名固定为 `ChaoxingHelper.exe`，覆盖即替换。
   —— 但如果你曾装过更早的实验版本（可执行文件叫 `学习通助手.exe`），那个文件不会被自动删除，建议手动清掉旧目录。

## 升级后建议做的两件事

1. 打开后看一眼右下角版本号，确认是新版
2. 如果这次更新涉及自动化逻辑，第一次跑建议先点「暂停」验证一节，再让它连续跑

## 如果要改成自动更新

需要额外这些，属于另一个工程量级：

- 引入 `electron-updater`
- 配置 `build.publish`（GitHub Releases 或自建静态服务器）
- 每个版本上传安装包 + `latest.yml`
- 程序启动时检查、差分下载、静默安装、重启

当前版本刻意没做，因为它是本地自用工具，手动覆盖已经够用且更可控。
