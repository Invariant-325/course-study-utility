# 0.1.2 变更：刷完视频先做本节测验，再做下一节

## 改了什么

以前 `advance()` 只找 video 任务点，找不到就直接切下一节——章节测验被跳过。

现在在「同页已无未完成视频」和「切下一节」之间插了一道闸门：

```
1.   同页还有未完成视频        → 播它
1.5  本节还有未完成章节测验    → 先做完测验（识别 → 填写 → 提交），做完再回到 1
2.   切下一节
3.   切不动了 → 评估完成度
```

## 关键设计

**1. 测验在 iframe 里**

连播跑在顶层 frame，测验页在 `#frame_content-zj` → `doHomeWorkNew`。`resolveQuizDoc()` 会遍历同源子框架找含 `.TiMu` 的文档，所以识别和填写作用在正确的 document 上。

**2. 自动提交会处理二次弹窗**

平台点「提交」后弹「提示 / 确认提交? / 取消 / 提交」。`submitAndConfirm()` 在可见弹层里找"提交/确定/确认"按钮并排除"取消"，找到才点。

**3. 任何一步不确定都转人工**

- 找不到测验入口 → `awaitingConfirm`，提示手动完成
- 打开后 20 秒没等到题目 → 转人工
- 识别/填写失败 → 转人工
- 没等到确认弹窗 → 仍标记已提交但记录 `no-confirm-dialog`

转人工时状态是 `awaitingConfirm`，你在面板点「继续」就会重新尝试推进。

## 一个要注意的点

**提交是自动的**（因为你要"做完才继续"）。如果某次识别结果不可靠，建议在流程开始时先点「暂停」，用面板手动核对一遍再继续。

想关掉闸门（回到只刷视频）：把配置 `quizGateEnabled` 设为 false。
